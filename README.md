# Philarkophy

Your website's files. Hosted free on GitHub Pages at **philarkophy.com**.

## How to add a new essay

1. In the `essays/` folder, make a copy of `why-philarkophy.html` and rename it
   (e.g. `on-friendship.html`). Use lowercase and dashes, no spaces.
2. Edit the copy: change the `<title>`, the `<h1>`, the date, and the essay text.
3. Open `index.html` and copy the "essay-item" block near the comment that says
   "TO ADD A NEW ESSAY". Paste it above the existing one (newest first), and
   change the link, title, date and summary to match your new essay.

You can do all of this on github.com — open the file, click the pencil icon to
edit, then "Commit changes". The live site updates in about a minute.

## Files

- `index.html` — homepage with the list of essays
- `about.html` — about page
- `essays/` — one HTML file per essay
- `styles.css` — the design (colors, fonts, layout)
- `CNAME` — tells GitHub Pages your custom domain (don't delete)
